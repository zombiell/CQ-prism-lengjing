# 08 尺寸测量与结构强度

> 对应中期考核指标 **8：尺寸规范**、**11：结构稳定性**

本篇记录机器人尺寸实测过程、与竞赛规则的逐项比对、以及结构稳定性（180mm 自由落体）测试。

---

## 尺寸规范验证

### 实测数据

| 维度 | 实测值 | 规则限值 | 余量 | 结论 |
| --- | --- | --- | --- | --- |
| 长度（前后） | **187 mm** | ≤ 290 mm | 103 mm | ✅ 通过 |
| 宽度（左右） | **169 mm** | ≤ 195 mm | 26 mm | ✅ 通过 |
| 高度 | **130 mm** | ≤ 210 mm | 80 mm | ✅ 通过 |
| **重量** | **1.08 kg** | ≤ 2.0 kg | **0.92 kg（余量 46%）** | ✅ 通过 |

> **测量对象说明**：以上数据为**底盘部分**（含 4 个麦克纳姆轮、电机、驱动、主控板、电池）。
> 集球/收集机构尚在设计中，**加装后需重新测量并更新本表**（见文末"后续变更记录"）。

### 测量方法

| 项目 | 方法 |
| --- | --- |
| 长度 | 直尺贴地，从**最前端轮子外缘**量到**最后端轮子外缘**（含轮胎挤出量） |
| 宽度 | 直尺贴地，量**左右两侧轮子外缘**的最远距离 |
| 高度 | 直尺垂直立于地面，从**地面量到车体最高点**（当前为主控板/电池盒顶部） |
| 测量姿态 | 车体**自然平放于水平地面**，四轮着地、无压缩变形 |

> **为什么按"轮子外缘"量**：规则中的尺寸指机器人的**最大外轮廓**。麦轮辊子比轮毂外凸，所以必须量到辊子最外缘，否则实际会超限。

## 与 550mm 球体规则的几何核算

规则要求：机器人放置于一个与地面平行、且**距离球心 180mm** 的平面上，在该平面上的**任意变形或移动不得超出该球体范围**（球体直径 550mm）。

### 核算过程

| 步骤 | 计算 | 结果 |
| --- | --- | --- |
| 球体半径 | 550 ÷ 2 | **275 mm** |
| 球心到放置平面距离 | 规则给定 | **180 mm** |
| 放置平面上的**截面圆半径** | √(275² − 180²) = √(75625 − 32400) = √43225 | **207.9 mm** |
| 即该平面允许的**最大外接圆直径** | 207.9 × 2 | **415.8 mm** |
| 机器人**实际外接圆直径** | √(187² + 169²) = √(34969 + 28561) = √63530 | **252.1 mm** |
| **平面方向余量** | 415.8 − 252.1 | **163.8 mm** ✅ |
| 球体允许的**最大高度**（球顶到地面） | 180 + 275 | **455 mm** |
| 当前车高 | — | **130 mm** |
| **高度方向余量** | 455 − 130 | **325 mm** ✅ |

### 结论

**当前底盘在球体规则下有充足余量**：
- 平面方向余量 163.8mm
- 高度方向余量 325mm

**这意味着后续加装集球机构有很大空间** —— 高度可再增加 325mm 以内、外轮廓可再扩展 163mm 以内都不违规。我们计划把收集机构的尺寸控制在这个余量内。

## 结构稳定性测试

### 测试要求

规则原文：**机器人从高 150mm~200mm（考核使用 180mm）处以底面朝下的初始姿态自由下落，无零件掉出则视为检测合格。**

### 测试方法

| 项目 | 做法 |
| --- | --- |
| 下落高度 | **180 mm**（用直尺量取，从车体底面到落地面） |
| 初始姿态 | **底面朝下**（保持车辆正常行驶姿态，不翻转） |
| 释放方式 | 双手托住车体，水平释放，**不施加额外初速度** |
| 落地面 | 硬质平整地面 |
| 判定标准 | 落地稳定后，**无任何零件脱落/掉出**（螺丝、轮子、电板、接线均不得脱离） |

### 测试结果

| 项目 | 结果 |
| --- | --- |
| 下落高度 | **180 mm**（直尺实测） |
| 初始姿态 | 底面朝下，水平释放，无初速度 |
| **是否有零件掉出** | ✅ **无零件掉出**（螺丝、轮子、电板、接线均保持连接） |
| **判定** | ✅ **检测合格** |
| 测试日期 | 2026-10-18 |
| 视频记录 | ✅ 已录制（`指标11_结构稳定性.mp4`） |

> **结论**：本机器人通过规则要求的结构强度检测（180mm 底面朝下自由落体无零件掉出）。

### 结构稳定性的设计保证

能通过跌落测试不是运气，是设计上的几个具体措施：

| 措施 | 作用 |
| --- | --- |
| **螺丝固定 + 金属底盘折弯板** | 不用热熔胶等易脱材料作为主承力结构（也符合规则"避免热熔胶组合"的要求） |
| **电机与底盘用螺丝+联轴器双重固定** | 防止跌落时电机移位或轮子脱出 |
| **电池盒扎带二次固定** | 电池最重，跌落冲击最大，必须额外绑扎 |
| **杜邦线插头朝内收拢 + 扎带整理** | 防止插头被甩出（也满足规则"布线不过度裸露"） |
| **主控板四角螺丝固定** | 避免板子跳出 |

> 这些措施同时也是规则"结构规范"里要求的：**建议采用较为牢固的材料搭建、避免热熔胶、建议采用集成电路板、布线合理不裸露**。
