## 文档撰写规范

本目录所有文档遵循以下约定（对应竞赛手册第 4.3.1 条）：

- 格式：**Markdown（.md）**
- 组织顺序：按**机器人开发进度的时间先后**分篇；每篇内部以 `##` 二级标题划分功能板块，正文写功能描述与开发历程
- 引用开源项目时，在文档末尾说明来源与许可证
