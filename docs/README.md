## 文档撰写规范

本目录所有文档遵循以下约定（对应竞赛手册第 4.3.1 条）：

- 格式：**Markdown（.md）**
- 组织顺序：按机器人设计进度的**时间先后**
- 结构单元：**单个功能为一个板块**，用 `##` 二级标题作板块名，正文写功能描述与开发历程
- 引用开源项目时，在文档末尾说明来源与许可证
