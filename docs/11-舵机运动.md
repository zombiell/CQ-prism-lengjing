### 预研技术点

| 技术点 | 方案 |
| --- | --- |
| 舵机 PWM 频率 | 50Hz（周期 20ms），与本项目电机 PWM 的 20kHz 不同，需单独的定时器通道 |
| 脉宽与角度 | 0.5ms → 0°，1.5ms → 90°，2.5ms → 180° |
| 多舵机同步 | 同一定时器的不同通道，共用 50Hz 时基 |
| 机构自锁 | 采用蜗轮蜗杆或大减速比齿轮组，使舵机断电后仍能保持位置 |
