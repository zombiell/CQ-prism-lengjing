# 05 麦克纳姆轮运动学解算

## 麦克纳姆轮为什么能横着走

### 普通轮 vs 麦克纳姆轮

普通轮子只能沿**滚动方向**前进后退，要横向移动必须先把车转向。

**麦克纳姆轮（Mecanum Wheel）** 的轮毂上斜装着约 45° 的一圈小**辊子**（roller）。辊子自身的轴线与轮毂成 45°，且能自由转动。当轮子转动时：

- 辊子与地面接触，**沿辊子轴线的方向可以自由滑动**
- **垂直于辊子轴线的方向产生推力**

所以一个麦轮对地面贡献的是一个 **45° 斜向的力**，而不是纯前后力。

### 四个轮子如何合成

四个麦轮按 **X 形布局**（从车顶往下看，辊子方向像个 X）：

```
          前
    FL ╱        ╲ FR        左轮的辊子方向：╱
       ╲        ╱           右轮的辊子方向：╲
    RL          RR
          后
```

- **四个轮子同向转** → 4 个 45° 力的横向分量**互相抵消**，纵向分量叠加 → **车前进**
- **左右两侧反向转** → 纵向分量抵消，横向分量叠加 → **车横移**
- **对角同向、另一对角反向** → 纵横向都抵消，只剩旋转 → **原地自转**

这就是全向移动的物理原理，也是麦轮相对普通轮的最大优势。

### 为什么选麦轮（三种全向方案对比）

| 方案 | 横向移动 | 机械复杂度 | 对装配精度要求 | 结论 |
| --- | --- | --- | --- | --- |
| **普通轮（差速）** | ❌ 不能 | 低 | 低 | 无法快速占位 |
| **全向轮（Omni）** | ✅ 能 | 中 | **高**（需独立悬挂才稳） | 装配难度大 |
| **麦克纳姆轮** | ✅ 能 | **低**（四轮固定安装） | 中 | **✅ 采用** |

麦轮的关键优势：**四个轮子直接固定在矩形底盘的四个角上**，不需要转向机构，也不需要独立悬挂。

## 坐标系与三个控制量

在写公式之前，先明确定义三个控制量：

| 符号 | 含义 | 正方向 |
| --- | --- | --- |
| **vx** | 前后平移速度 | **+1.0 = 全速向前** |
| **vy** | 左右平移速度 | **+1.0 = 全速向右** |
| **w** | 原地自转角速度 | **+1.0 = 顺时针**（从车顶往下看） |

三者可以**任意组合**，例如 `vx=0.5, w=0.5` 就是"一边前进一边顺时针转"。

## 逆运动学推导

### 正解与逆解

| 类型 | 已知 | 求解 | 用途 |
| --- | --- | --- | --- |
| **正运动学** | 四个轮子的转速 | 车体速度 (vx, vy, w) | 装编码器时算里程 |
| **逆运动学（本项目用）** | 车体期望速度 (vx, vy, w) | 四个轮子各自的转速 | 遥控行驶 |

### 推导思路

对**每个轮子**，它受到的指令来自三部分的叠加：

1. 车体前后运动 `vx` 对该轮的分量
2. 车体左右运动 `vy` 对该轮的分量（**左右轮的辊子方向镜像，所以符号相反**）
3. 车体旋转 `w` 对该轮的分量（**对角轮同号**）

### 最终公式

```c
d[MOTOR_FL] = vx + vy + w;      /* 前左 */
d[MOTOR_FR] = vx - vy - w;      /* 前右 */
d[MOTOR_RL] = vx - vy + w;      /* 后左 */
d[MOTOR_RR] = vx + vy - w;      /* 后右 */
```

### 符号规律解读

| 轮子 | vx | vy | w | 说明 |
| --- | --- | --- | --- | --- |
| **FL 前左** | + | **+** | **+** | vy 与前左同号，w 顺时针时前左向前 |
| **FR 前右** | + | **−** | **−** | vy 反号（右轮镜像），w 反号（顺时针时前右向后） |
| **RL 后左** | + | **−** | **+** | vy 反号（后轮镜像），w 与前左同号 |
| **RR 后右** | + | **+** | **−** | vy 与前左同号，w 与前右同号 |

**三条规律**：

- **vx 全为正**：四个轮子都往前转 → 车前进（符合直觉）
- **vy 左正右负**：左侧两轮 +，右侧两轮 − → 左右反向转 → 横移
- **w 对角同号**：FL 与 RL 同号、FR 与 RR 同号，且两对反号 → 旋转

### 验证：四种基本动作

| 动作 | vx | vy | w | FL | FR | RL | RR | 物理意义 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| **前进** | +1 | 0 | 0 | +1 | +1 | +1 | +1 | 四轮同向 ✅ |
| **右移** | 0 | +1 | 0 | +1 | −1 | −1 | +1 | 两侧反向 ✅ |
| **顺时针转** | 0 | 0 | +1 | +1 | −1 | +1 | −1 | 对角同号 ✅ |
| **右前斜行** | +1 | +1 | 0 | +2 | 0 | 0 | +2 | 只有 FL/RR 出力 ✅ |

**斜行时只有 2 个轮子出力**，这是麦轮的固有特性，也是本项目排查故障时的关键线索（详见 [09](./09-调试过程与问题排查.md)）。

## 归一化处理

### 问题：某个轮子会超过 100%

考虑"全速右前斜行"：`vx = 1.0, vy = 1.0, w = 0`

```
FL = 1.0 + 1.0 + 0 = 2.0    ← 要求 200% 转速，做不到！
FR = 1.0 - 1.0 - 0 = 0
RL = 1.0 - 1.0 + 0 = 0
RR = 1.0 + 1.0 - 0 = 2.0    ← 同样超限
```

### 错误做法：各自截断

如果简单地各自限幅到 100%：

```
FL = 1.0,  FR = 0,  RL = 0,  RR = 1.0
```

看似能用，但如果同时还有旋转，例如 `vx=1.0, vy=1.0, w=0.5`：

```
原始计算:  FL = 2.5,  FR = -0.5,  RL = 0.5,  RR = 1.5
各自截断:  FL = 1.0,  FR = -0.5,  RL = 0.5,  RR = 1.0
```

**四个轮子的相对比例被破坏了** → 合成出的运动方向不对 → **车会走偏**，而不是走斜。

### 正确做法：整体等比缩放

```c
/* 1. 找出绝对值最大的那个 */
float peak = 0.0f;
for (uint8_t i = 0; i < MOTOR_COUNT; i++) {
    float a = fabsf(d[i]);
    if (a > peak) peak = a;
}

/* 2. 如果超过 1.0，四个一起除以 peak */
if (peak > 1.0f) {
    for (uint8_t i = 0; i < MOTOR_COUNT; i++) {
        d[i] /= peak;
    }
}
```

效果：

```
原始:  FL = 2.5,  FR = -0.5,  RL = 0.5,  RR = 1.5    (peak = 2.5)
归一化: FL = 1.0,  FR = -0.2,  RL = 0.2,  RR = 0.6    (全部 ÷ 2.5)
```

**比例保持**：`2.5 : -0.5 : 0.5 : 1.5` = `1.0 : -0.2 : 0.2 : 0.6` ✅

### 归一化的三个性质

| 性质 | 说明 |
| --- | --- |
| **最大的一路正好满速** | 不浪费动力 |
| **相对比例完全不变** | 合成方向正确 |
| **代价是整体降速** | 在"既要又要"时，保证方向正确比保证速度重要 |

### 一个反直觉的结论

**斜行的轮子比直行跑得更快。**

| 动作 | 计算 | peak | 归一化后每个轮子的 duty |
| --- | --- | --- | --- |
| **直行**（vx=0.6） | FL=FR=RL=RR=0.6 | 0.6 | **0.60**（不触发归一化） |
| **斜行**（vx=0.6, vy=0.6） | FL=RR=1.2, FR=RL=0 | 1.2 | **1.00**（触发归一化） |

这个差异正是本项目"斜行能走、直行不走"故障的根源 —— 详见 [09](./09-调试过程与问题排查.md)。

## 四轮降额（可选，当前已关闭）

### 设计初衷

曾经怀疑"4 个轮子同时出力会拉垮电源"，因此在四个轮子都要出力时统一降额：

```c
#define CHASSIS_FOUR_WHEEL_SCALE   1.00f    /* 当前 = 1.00，即关闭 */
#define CHASSIS_WHEEL_ACTIVE_EPS   0.01f

uint8_t active = 0;
for (uint8_t i = 0; i < MOTOR_COUNT; i++) {
    if (fabsf(d[i]) > CHASSIS_WHEEL_ACTIVE_EPS) active++;
}

float scale = 1.0f;
if (active == MOTOR_COUNT) {
    scale = CHASSIS_FOUR_WHEEL_SCALE;     /* 4 轮出力时缩放 */
}
```

### 为什么现在关闭了

实测证明，降额**对当时的故障毫无帮助**（真正原因是马达死区，见 [09](./09-调试过程与问题排查.md)）。把四轮降到 0.30 反而让力矩更小，问题更严重。

**代码保留但系数设为 1.00（等于不生效）**，万一以后确认存在电源瓶颈可以改回 0.50。

### 踩过的坑：按"总电流"等比缩放会放大输出

最初的设计是"把四轮 duty 绝对值之和当作电流，超过预算就等比缩小"：

```
预算 1.6，四轮 load = 2.4 → 缩放系数 k = 1.6/2.4 = 0.667  ✓ 合理
预算 1.6，两轮 load = 1.2 → 缩放系数 k = 1.6/1.2 = 1.333  ✗ 放大了！
```

**限制器只能往下压，不能往上抬。** 所以最终改成"固定系数 + 判断是否四轮出力"，避免这个陷阱。

## 方向标定机制

### 为什么需要标定

实际装配中可能出现：

- 电机两根线接反了
- 麦轮辊子装反了（左右轮装错位置）
- 某一侧的电机安装方向相反

这些都会导致轮子转的方向和公式预期相反。

### 解决：符号数组（不用重新接线）

```c
static int8_t sgn[MOTOR_COUNT] = { +1, +1, +1, +1 };   /* 默认全部正向 */

void chassis_set_sign(int8_t s_fl, int8_t s_fr, int8_t s_rl, int8_t s_rr)
{
    sgn[MOTOR_FL] = (s_fl >= 0) ? +1 : -1;
    sgn[MOTOR_FR] = (s_fr >= 0) ? +1 : -1;
    sgn[MOTOR_RL] = (s_rl >= 0) ? +1 : -1;
    sgn[MOTOR_RR] = (s_rr >= 0) ? +1 : -1;
}
```

使用方法：如果发现**后左轮方向相反**，在主程序初始化时调用：

```c
chassis_set_sign(+1, +1, -1, +1);   /* 第三参数为 RL */
```

**不用拆线、不用焊接**，改一个数字就能纠正。

### `sgn[]` 为什么提前到"数轮子"之前

方向上，`sgn[]` 的乘法原本放在最后输出前。但"四轮降额"需要先判断**实际有几个轮子在出力**，如果某个轮子的 `sgn = -1`，它的值会变号，必须先把符号乘进去才能正确统计。

所以现在的顺序是：

```
1. 逆运动学分解
2. 归一化（峰值 ≤ 1.0）
3. 方向标定（乘 sgn[]）      ← 提前到这里
4. 数有几个轮子出力 → 四轮降额
5. 死区补偿 + 斜坡 + PWM 输出
```

## 完整调用链

```
main.c
  ├─ 读手柄 → vx/vy/w
  └─ chassis_mecanum(vx, vy, w)
        │
        ├─ 1. 逆运动学分解：d[FL/FR/RL/RR]
        ├─ 2. 归一化：找 peak，超过 1.0 就整体缩放
        ├─ 3. 方向标定：d[i] *= sgn[i]
        ├─ 4. 四轮降额：active == 4 时乘 SCALE（当前 1.00，不生效）
        └─ 5. 每个轮子调 motor_set_ramp(d[i])
                │
                ├─ 死区补偿：线性映射到 [0.80, 1.00]
                ├─ 斜坡：每次逼近一小步
                └─ motor_set() → __HAL_TIM_SET_COMPARE → 硬件 PWM
```

## 本节小结

| 要点 | 结论 |
| --- | --- |
| 麦轮全向原理 | 45° 辊子产生斜向力，四轮合成出任意方向运动 |
| 逆运动学 | 四行公式，vx 全正、vy 左正右负、w 对角同号 |
| 归一化 | 必须做，且必须整体等比缩放，否则方向会变形 |
| 关键反直觉点 | **斜行时单个轮子比直行跑得快**（1.00 vs 0.60） |
| 降额 | 保留但当前关闭（实测证明与故障无关） |
| 方向标定 | `sgn[]` 数组，改数字不用改接线 |
