# 07 电源管理与电气规范

## 电源方案总览

```
2S 18650 锂电池组
（2 × 3.7V 标称 = 7.4V，满电 8.4V）
        │
        ├──────────────────────► DRV8833 #1 的 VM ──► TT 马达 FL / FR
        │                         DRV8833 #2 的 VM ──► TT 马达 RL / RR
        │                        （电机电源，直供 7.4V）
        │
        └──► DC-DC 降压模块 ──► 5V ──► STM32 核心板（板载再降到 3.3V）
                                    └─► PS2 接收器 VCC
```

**为什么分两路**：

| 负载 | 电压需求 | 供电方式 | 原因 |
| --- | --- | --- | --- |
| TT 马达 | 3~6V（额定），7.4V 可短时工作 | **直供电池** | 需要大电流和高电压才有扭矩 |
| STM32 / 接收器 | 3.3V / 5V 逻辑电平 | **经 DC-DC 降压** | 直接接 7.4V 会烧毁 |

## 电池选型与规则符合性

### 电池配置

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 电池类型 | **18650 锂离子电池** | 竞赛规则指定使用 18650 |
| 配置 | **2 节串联（2S）** | 装于两节带线电池盒中 |
| **额定电压** | **7.4V**（2 × 3.7V） | 规则限值 |
| 满电电压 | 8.4V（2 × 4.2V） | 锂电满电时的开路电压 |
| 实测空载电压 | **8.0V** | 电量约 70~80% 时的实测值 |
| 供电模块数量 | **1 个**（1 个两节电池盒，单输出接口） | 规则要求"仅允许 1 个供电模块" |

### 关于"额定电压"与"满电电压"的区别

**规则原文**（手册 3.2 通用技术规范）：

> 每台机器人仅允许安装 1 个供电模块，且**供电模块额定电压不超过 7.4V**。

**我们的理解**：

| 概念 | 数值 | 是否受规则限制 |
| --- | --- | --- |
| **额定电压（nominal voltage）** | 2S = **7.4V** | ✅ **符合 ≤7.4V 要求** |
| 满电电压（开路，瞬时） | 8.4V | 锂电固有特性，不等于额定值 |
| 实测空载电压 | 8.0V | 满电到放电中的中间状态 |

**类比说明**：手机电池标称 3.7V，满电也是 4.2V —— 这是锂离子电池的普遍特性。规则约束的是**电池组的额定规格**（2S = 7.4V），而不是满电瞬间的开路电压。

**结论：本机器人电源方案符合规则要求。**

### 供电模块数量的判定

规则补充说明：

> 供电模块定义为**有且仅有一个输出接口**，如 XT30 接口、一对杜邦线头等的供电装置。如无线继电器与电池组前存在延长线或转接线，则**按照离电池组最近的一端计算接口数量**。

本项目使用**一个两节 18650 电池盒**，它只有**一对输出线**，因此计为 **1 个供电模块** ✅

## 各部件功耗估算

| 部件 | 电压 | 典型电流 | 功率 |
| --- | --- | --- | --- |
| STM32F103C8T6 | 3.3V | 约 30mA | 0.1 W |
| PS2 接收器 | 3.3V | 约 20mA | 0.07 W |
| DRV8833 静态 | 7.4V | 约 5mA ×2 | 0.07 W |
| **4 × TT 马达（空载）** | 7.4V | 约 150mA ×4 | 4.4 W |
| **4 × TT 马达（正常行驶）** | 7.4V | 约 300~500mA ×4 | 9~15 W |
| **4 × TT 马达（堵转）** | 7.4V | 约 1.0~1.5A ×4 | 30~44 W |

**结论**：

- 逻辑部分功耗极小（< 0.5W），可忽略
- **电机是唯一的大功耗源**，也是电源设计的核心矛盾
- 堵转时瞬时电流可达 **4~6A**，因此电池需具备足够的放电能力

## DC-DC 降压模块

### 为什么不用线性稳压（如 AMS1117）

| 方案 | 效率 | 发热 | 结论 |
| --- | --- | --- | --- |
| AMS1117（线性） | 3.3/7.4 ≈ **45%** | 剩余 55% 全部变成热量，会烫手甚至热保护 | ❌ |
| **Mini DC-DC 降压模块（开关式）** | **约 85~90%** | 发热很小 | ✅ 采用 |

用线性稳压时，若 MCU + 接收器共 50mA，则损耗 = (7.4 − 5) × 0.05 = **0.12W**，看似不大，但用 3.3V 直降时损耗更大。**开关式降压是正确选择**，且商品模块只要 ¥2 左右。

### 接线

| 输入端 | 输出端 |
| --- | --- |
| VIN+ ← 电池正极 | VOUT+ → STM32 的 5V 引脚 |
| VIN− ← 电池负极（GND） | VOUT− → GND |

> 上电前**必须先用万用表确认输出是 5V** 再接到 MCU，否则可能瞬间烧板。

## 共地：最容易出玄学问题的地方

### 必须共地的所有部件

```
电池负极 ───┬─── STM32 的 GND
            ├─── DRV8833 #1 的 GND
            ├─── DRV8833 #2 的 GND
            ├─── DC-DC 降压模块的 GND
            └─── PS2 接收器的 GND   ★ 最容易漏
```

### 不共地会出现什么

| 现象 | 原因 |
| --- | --- |
| 串口能打印，但电机不转 | 逻辑地和功率地没有共同参考点，PWM 电平判定失效 |
| 电机转一下停一下 | 地线浮动导致驱动芯片误判输入 |
| 手柄偶尔读不到数据 | 接收器地线悬空，信号参考电平不稳 |
| 时好时坏，找不到规律 | 典型的接地不良表现 |

**排查方法**：用万用表**通断档**，逐个测量各模块 GND 与电池负极之间的导通性。

## 电源保护

| 保护项 | 措施 | 说明 |
| --- | --- | --- |
| **防反接** | 电池盒带线正负极严格区分、接线前确认 | 接反会瞬间烧毁 DRV8833 |
| **欠压保护** | DRV8833 内置 UVLO（欠压锁定） | 电池电压过低时自动关断输出 |
| **过流保护** | DRV8833 内置过流保护（每路 1.5A 持续） | 堵转时自动限流 |
| **过热保护** | DRV8833 内置热关断 | 芯片过热时关断 |
| **占空比限制** | 软件限幅 `MOTOR_DUTY_LIMIT = 0.85f` | 从源头限制平均电流 |

> **软件保护比硬件保护更早介入**：`MOTOR_DUTY_LIMIT` 让占空比永远不超过 85%，从而限制平均电压和电流，减少触发芯片内部保护的机会。

## 与规则中其他电气要求的对照

| 规则要求 | 本机器人情况 | 符合 |
| --- | --- | --- |
| 电池类型为 18650 | 18650 锂离子电池 | ✅ |
| 仅 1 个供电模块 | 单个两节电池盒（单输出接口） | ✅ |
| 额定电压 ≤7.4V | 2S = 7.4V 额定 | ✅ |
| 电池故障造成的危险由队伍负责 | 使用带保护板的 18650，接线规范 | ✅ |

### 关于无线继电器

规则要求机器人必须适配官方指定的无线继电器，使底盘电源能在 10m 范围内被单独遥控切断。

规则同时说明：**通过中期测评的队伍才需要购买无线继电器**。

因此本项目在中期考核阶段未加装无线继电器，将在通过考核后按官方要求加装。

## 电源带来的一个真实故障教训

在排查"斜行能走、直行不走"的故障时，我们最初怀疑是**电源带不动 4 个电机**，并为此做了大量验证：

| 验证项目 | 结果 | 结论 |
| --- | --- | --- |
| 按住 ↑ 时测电机电源电压 | **稳定 8.0V 不掉** | 没有大电流 → 不是电源问题 |
| 按住斜行时测电压 | 7.33V（掉了 0.67V） | 有电流 → 说明电机在转 |
| 拔掉 1 个电机再测 | 剩下的仍不转 | 与负载数量无关 |
| 拔掉 2 个电机再测 | 剩下的仍不转 | 与负载数量无关 |

**最终结论**：电源完全正常，真正原因是**马达静摩擦死区**（见 [04 电机驱动与PWM调速](./04-电机驱动与PWM调速.md) 与 [09](./09-调试过程与问题排查.md)）。

**这个教训很有价值**：电机电源电压"不掉"看似是好消息，实际上说明**电机根本没有在工作** —— 直流电机只要有电流就必然产生力矩。这个反直觉的判据后来成为定位故障的关键。

## 本节小结

| 要点 | 结论 |
| --- | --- |
| 供电方案 | 2S 18650（额定 7.4V），1 个供电模块，符合规则 |
