# 06 底盘结构与外形

> 对应中期考核指标 **1：外形展示**

## 外形展示

### 功能说明

机器人是一台**具备能量单元的完整机体**，能够绕车一周展示整车外形。对应中期考核指标 1。

### 整车构成

| 部件 | 规格 | 数量 | 安装位置 |
| --- | --- | --- | --- |
| 金属底盘 | 4 轮金属底盘折弯板（一体带马达孔） | 1 | 主体 |
| TT 减速马达 | 单轴 1:48 | 4 | 底盘四角，螺丝固定 |
| 麦克纳姆轮 | 60mm 黄色麦轮 | 4 | 电机轴，联轴器固定 |
| DRV8833 驱动模块 | 双路 H 桥 | 2 | 底盘上方，尼龙柱支撑 |
| STM32F103C8T6 核心板 | Micro-USB 接口版 | 1 | 底盘上层 |
| 18650 电池盒 | 两节带线 | 1 | 底盘中部（重心居中） |
| DC-DC 降压模块 | Mini 5V 降压 | 1 | 靠近电池盒 |
| PS2 接收器 | 2.4GHz 无线 | 1 | 底盘上层，天线朝上 |

### 整车外形尺寸

| 维度 | 实测值 | 规则限值 | 余量 |
| --- | --- | --- | --- |
| 长度（前后） | **187 mm** | ≤ 290 mm | 103 mm |
| 宽度（左右） | **169 mm** | ≤ 195 mm | **26 mm** |
| 高度 | **130 mm** | ≤ 210 mm | 80 mm |

> 详细测量方法与 550mm 球体规则核算见 [08 尺寸测量与结构强度](./08-尺寸测量与结构强度.md)。

### 外形展示的拍摄要点

| 项目 | 要求 |
| --- | --- |
| 拍摄方式 | 手机/相机**围绕机器人转一周**（约 360°） |
| 必须可见 | 四个麦轮、底盘、主控板、电池、**能量单元** |
| 光线 | 均匀照明，避免逆光导致零件看不清 |
| 时长 | 10~20 秒足够，无需旁白 |
| 分辨率 | ≥1080p，≥30fps（与所有演示视频统一） |

### 能量单元的安装

竞赛规则要求机器人携带**能量单元（白色立方体，30×30×30mm，内部镂空 15×15×15mm）**。

本项目在底盘上层预留了安装位，能量单元放置后由结构限位固定，行驶中不会脱落。收集机构完成后，能量单元将改由机构持有。

## 底盘结构设计

### 为什么采用"折弯板 + 四角电机"布局

| 设计选择 | 理由 |
| --- | --- |
| **金属折弯板**（非亚克力平板） | 折弯形成加强筋，同等厚度下抗弯刚度高得多，且自带电机安装孔位，省去二次加工 |
| **四角对称布置电机** | 麦轮运动学假设四个轮子位于矩形的四个角，对称布置才能保证逆运动学公式成立 |
| **电池居中放置** | 电池是最重的部件（约 90g），放在几何中心可降低转动惯量，提升自转响应速度 |
| **驱动模块靠近电机** | 缩短大电流走线长度，减少线路压降和干扰 |
| **主控板与驱动分层** | 避免电机大电流对 MCU 的干扰，也便于分别调试 |

### 车体尺寸与麦轮安装的关系

麦轮速比与轮距、轴距有关。本项目的实际尺寸：

| 参数 | 数值 |
| --- | --- |
| 轴距（前后轮中心距） | 约 130 mm |
| 轮距（左右轮中心距） | 约 115 mm |
| 轮子直径 | 60 mm |

由于逆运动学公式中的 vx / vy / w 都做了**归一化**处理（见 [05](./05-麦克纳姆轮运动学解算.md)），所以**不需要精确标定轮距轴距**就能得到正确的运动方向 —— 代价是实际速度不能精确换算成 mm/s。对遥控操作来说这完全够用。

### 装配流程

| 步骤 | 内容 | 注意事项 |
| --- | --- | --- |
| 1 | 底盘折弯板就位，四个电机从内侧穿入安装孔 | 电机轴朝外，螺丝从内侧拧紧 |
| 2 | 四个麦轮套上联轴器，装到电机轴 | **注意左右轮的辊子方向是镜像的**，装反会导致横移方向相反 |
| 3 | 驱动模块用尼龙柱架高固定在底盘上方 | 与底盘保持 5mm 以上间隙，避免短路 |
| 4 | 主控板固定在上层 | 四角螺丝，防止跌落时跳出 |
| 5 | 电池盒放置并**用扎带二次绑扎** | 电池最重，跌落冲击最大，必须有额外固定 |
| 6 | 走线：电源线走一侧、信号线走另一侧 | 避免电源干扰信号 |
| 7 | 杜邦线插头朝内收拢，用扎带整理 | 防止跌落时插头被甩出 |

### 麦轮辊子方向的判定方法

这是装配中最容易搞错的一步。**从车顶往下看**：

```
        前端
   FL ╱     ╲ FR
      ╲     ╱
   RL        RR
        后端
```

- **左侧两个轮子（FL、RL）**：辊子应呈 `╱` 方向（从左下到右上）
- **右侧两个轮子（FR、RR）**：辊子应呈 `╲` 方向（从左上到右下）

如果装反了，现象是**横移方向与预期相反**（按 → 却向左移）。此时有两种解决办法：

1. 拆下来重装（麻烦）
2. **改符号标定**：`chassis_set_sign()` 里把该轮参数改成 −1（推荐）

## 结构强度设计

### 规则要求

> 机器人从高 150mm~200mm（考核使用 180mm）处以底面朝下的初始姿态自由下落，**无零件掉出**则视为检测合格。

### 为此做的 5 项措施

| 措施 | 防的是什么 |
| --- | --- |
| **螺丝固定 + 金属底盘折弯板** | 不用热熔胶等易脱材料作主承力结构 |
| **电机螺丝 + 联轴器双重固定** | 防止电机移位或轮子脱出 |
| **电池盒扎带二次绑扎** | 电池最重，跌落冲击最大 |
| **杜邦线插头朝内收拢 + 扎带整理** | 防止插头被甩出 |
| **主控板四角螺丝固定** | 避免板子跳出 |

### 测试结果

**已完成 180mm 底面朝下自由落体测试，无零件掉出，检测合格。** 详见 [08](./08-尺寸测量与结构强度.md)。

## 结构规范符合性

| 规则要求 | 本机器人做法 | 符合 |
| --- | --- | --- |
| 建议采用较为牢固的材料 | 金属折弯底盘 + 尼龙柱 + 螺丝 | ✅ |
| 尽量避免采用热熔胶与其他物质组合 | 全部使用螺丝/联轴器/扎带固定，**未使用热熔胶作结构** | ✅ |
| 线路设计建议采用集成电路板，单一使用杜邦线易脱落 | 核心连接使用板上排针，杜邦线均加扎带固定 | ✅ |
| 布线合理，不允许线路过度裸露 | 电源线与信号线分侧走线，扎带收拢 | ✅ |
| 不得携带尖锐物体 | 所有零件均为圆角或平面，无尖锐突出 | ✅ |
| 不得携带易燃易爆、有毒有害化学物质 | 无任何化学品 | ✅ |
| 不得携带可沾染或污损场地的粉末或液体 | 无粉末液体 | ✅ |

## 后续规划

集球/收集机构完成后，需要在底盘上追加结构。根据 [08](./08-尺寸测量与结构强度.md) 的球体规则核算，当前仍有充足余量：

| 方向 | 可用余量 |
| --- | --- |
| 高度 | 还可增加 **325 mm** |
| 平面外轮廓 | 还可扩展 **163.8 mm** |

**因此追加收集机构不会超出规则限制**，但追加后必须重新测量尺寸并重做跌落测试。
