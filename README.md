> 重庆大学机器人训练大赛（CRTC2026）参赛作品
> 队伍：**CQ prism 棱镜战队**　队长：**李汶骏**

## 项目简介

本项目是一台基于 **STM32F103C8T6** 微控制器的四轮**麦克纳姆轮**全向移动机器人，通过 **PS2 无线手柄**遥控，能够实现**前进、后退、左移、右移、斜向移动、原地自转**等全向运动。

机器人的开发重点在于**底层驱动的从零实现**：PS2 手柄的通信协议由软件模拟时序实现，电机 PWM 与正反转切换由定时器直接控制，麦克纳姆轮的逆运动学解算与死区补偿算法均在固件中自行推导与实现。

## 技术规格

| 项目 | 参数 |
| --- | --- |
| 主控芯片 | STM32F103C8T6（ARM Cortex-M3，72MHz，64KB Flash，20KB RAM） |
| 电机驱动 | DRV8833 双 H 桥驱动模块 **× 2**（每模块驱动 2 个电机） |
| 电机 | TT 减速马达 × 4（单轴 1:48） |
| 轮系 | 60mm 麦克纳姆轮 × 4（X 形布局） |
| 遥控方式 | PS2 无线手柄 + 接收器（2.4GHz） |
| PWM 频率 | 20kHz（72MHz ÷ 3600） |
| 遥控信号刷新率 | 100Hz（每 10ms 一次） |
| 供电 | **2S 18650 锂电池组**（额定 **7.4V**，满电 8.4V，实测空载 8.0V），仅 1 个供电模块 |
| 调试接口 | USART1 @ 115200bps |
