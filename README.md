## 项目简介

本项目是一台基于 **STM32F103C8T6** 微控制器的四轮**麦克纳姆轮**全向移动机器人，通过 **PS2 无线手柄**遥控，能够实现**前进、后退、左移、右移、斜向移动、原地自转**等全向运动。

机器人的开发重点在于**底层驱动的从零实现**：PS2 手柄的通信协议由软件模拟时序实现，电机 PWM 与正反转切换由定时器直接控制，麦克纳姆轮的逆运动学解算与死区补偿算法均在固件中自行推导与实现。

## 技术规格

| 项目 | 参数 |
| --- | --- |
| 主控芯片 | STM32F103C8T6（ARM Cortex-M3，72MHz，64KB Flash，20KB RAM） |
| 电机驱动 | DRV8833 双 H 桥驱动模块 × 2 |

## 固件结构

| 文件 | 层次 | 职责 |
| --- | --- | --- |
| `Core/Src/ps2.c` | 驱动层 | 软件模拟 SPI 时序，读取 PS2 手柄 9 字节数据帧并校验 |
| `Core/Src/motor.c` | 驱动层 | 浮点占空比 → 定时器比较值；含软启动斜坡与**马达死区补偿** |
| `Core/Src/chassis.c` | 算法层 | 麦轮逆运动学解算、归一化、四轮降额 |
| `Core/Src/main.c` | 应用层 | 时间片调度、按键解析、急停安全逻辑、调试打印 |

## 快速开始

1. 用 STM32CubeIDE 或 CMake + arm-none-eabi-gcc 打开 `firmware/` 目录
2. 编译生成 `.hex` / `.bin`
3. 用 ST-Link 烧录到 STM32F103C8T6
4. 按接线表连接 PS2 接收器（DATA→PA4、CMD→PA5、CS→PA6、CLK→PA7）
5. 上电后**先按一次 START** 解除急停，即可用手柄遥控
