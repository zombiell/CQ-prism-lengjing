# CRTC2026 参赛机器人 —— 四轮麦克纳姆轮全向移动平台

> 重庆大学机器人训练大赛（CRTC2026）参赛作品
> 队伍：**CQ prism 棱镜战队**　队长：**李汶骏**

## 项目简介

本项目是一台基于 **STM32F103C8T6** 微控制器的四轮**麦克纳姆轮**全向移动机器人，通过 **PS2 无线手柄**遥控，能够实现**前进、后退、左移、右移、斜向移动、原地自转**等全向运动。

机器人的开发重点在于**底层驱动的从零实现**：PS2 手柄的通信协议由软件模拟时序实现，电机 PWM 与正反转切换由定时器直接控制，麦克纳姆轮的逆运动学解算与死区补偿算法均在固件中自行推导与实现。

## 技术规格

| 项目 | 参数 |
| --- | --- |
| 主控芯片 | STM32F103C8T6（ARM Cortex-M3，72MHz，64KB Flash，20KB RAM） |
| 电机驱动 | DRV8833 双 H 桥驱动模块 **× 2**（每模块驱动 2 个电机） |
| 电机 | TT 减速马达 × 4（单轴 1:48） |
| 轮系 | 60mm 麦克纳姆轮 × 4（X 形布局） |
| 遥控方式 | PS2 无线手柄 + 接收器（2.4GHz） |
| PWM 频率 | 20kHz（72MHz ÷ 3600） |
| 遥控信号刷新率 | 100Hz（每 10ms 一次） |
| 供电 | **2S 18650 锂电池组**（额定 **7.4V**，满电 8.4V，实测空载 8.0V），仅 1 个供电模块 |
| 调试接口 | USART1 @ 115200bps |

## 固件结构

| 文件 | 层次 | 职责 |
| --- | --- | --- |
| `Core/Src/ps2.c` | 驱动层 | 软件模拟 SPI 时序，读取 PS2 手柄 9 字节数据帧并校验 |
| `Core/Src/motor.c` | 驱动层 | 浮点占空比 → 定时器比较值；含软启动斜坡与**马达死区补偿** |
| `Core/Src/chassis.c` | 算法层 | 麦轮逆运动学解算、归一化、四轮降额 |
| `Core/Src/main.c` | 应用层 | 时间片调度、按键解析、急停安全逻辑、调试打印 |

## 快速开始

1. 用 STM32CubeIDE 或 CMake + arm-none-eabi-gcc 打开 **`firmware/`** 目录（源码根目录含 `CMakeLists.txt`）
2. 编译生成 `.hex` / `.bin`
3. 用 ST-Link 烧录到 STM32F103C8T6
4. 按下表连接 PS2 接收器：

   | 接收器引脚 | STM32 引脚 |
   | --- | --- |
   | GND | GND |
   | VCC | 3.3V 或 5V |
   | DATA | PA4 |
   | CMD | PA5 |
   | CS | PA6 |
   | CLK | PA7 |

5. 上电后**先按一次 START 键**解除急停锁存，即可用手柄遥控

## 操作映射

| 手柄按键 | 机器人动作 |
| --- | --- |
| ↑ / ↓ | 前进 / 后退 |
| ← / → | 左移 / 右移 |
| ↑ + ← / ↑ + → 等 | 斜向 45° 移动（四组） |
| ○ / □ | 原地顺时针 / 逆时针自转 |
| 方向键 + ○/□ | 边走边转 |
| **START** | 解除急停锁存 |
| **SELECT** | 紧急停车（锁存，需 START 解除） |

> 本手柄摇杆无模拟量输出（官方手册明确说明），因此**必须使用十字方向键**控制，推摇杆不会产生平移。
